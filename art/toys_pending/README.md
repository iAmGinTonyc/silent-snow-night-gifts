# Игрушки по уровням (сгенерировано 18.11.2026, ещё не подключено)

Папка скрыта от Godot (`.gdignore`), чтобы неиспользуемые картинки не раздували сборку. Когда подключим, переносим нужные файлы в `art/shop/` (вид спереди) и `art/wrap/` (вид сверху) и запускаем импорт.

Имена: `item_<вид>_<уровень>.png` (спереди, для полки), `top_<вид>_<уровень>.png` (сверху, для упаковки), `item_<вид>_bad.png` и `item_<вид>_mid_bad.png` (с браком, для проверки ящика). Виды: bear, ornament, ball, train. Уровни: mid, prem. Дешёвые версии уже в игре (`art/shop/item_*.png`, `art/wrap/top_*.png`).

Известные недочёты: у `item_ornament_mid_bad` рисунок похож на дорогой хрустальный шар, а у `item_train_mid_bad` смесь средней и дорогой модели. Если дойдём до проверки ящика, эти два стоит перегенерировать. Исходные листы лежат в `art/source/` (`toys_tiers_front.png`, `toys_tiers_top.png`, `toys_broken.png`).
