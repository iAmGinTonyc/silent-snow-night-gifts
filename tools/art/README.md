# Скрипты для картинок

Этими скриптами резались и обрабатывались картинки игры. Сами генерации делались в Higgsfield, модель `nano_banana_2_1`, разрешение 4k. Исходные листы лежат в `art/source/` (в git не попадают).

В скриптах жёстко прописаны пути временной папки, где они писались (`/private/tmp/claude-501/.../scratchpad/`). Перед запуском поправь пути в начале файла. Нужны Python 3 и Pillow с numpy; scipy и opencv не нужны.

| Скрипт | Что делает |
|---|---|
| `make_customers.py` | старая нарезка клиентов; из неё берутся `grid()` и `flood()` |
| `recut_customers.py` | клиенты из листов `sheet_*.png`: маска в полном размере, целый контур, без светлой каймы, высота 480 px. Задания вида `[["leo","sheet_E3.png",1,1.0,[0,1,2,3,5,5,6]], …]` (вид, лист, ряд, доля высоты, перестановка столбцов) |
| `recut_santa.py` | Санта из `santa_sheet.png` (6 поз, раскладка `MAPPING`) |
| `align_frames.py` | выравнивает кадры каждого клиента по телу, чтобы при смене лица он не дёргался; у Лео подставляет тело из кадра 0. Печатает новые точки рта (`MOUTHS` в `customer_view.gd`) |
| `pal_alpha.py` | палитровый PNG с гладким краем: 192 цвета без прозрачности плюс 8 цветов края × 7 уровней прозрачности |
| `angry_in.py`, `angry_cut2.py` | злое лицо (кадр 7): лист-образец 5×2 из кадра 1, затем вырезка и подгонка по силуэту |
| `shape_in.py`, `shape_out.py` | упаковка по контуру: лист с точными силуэтами (как в `shapes.gd`, плюс отступ и хвост), вырезка, подгонка и раскраска во все бумаги `Data.PAPERS` → `art/wrap/shape_<вид>_<бумага>.png`. Печатает `ART_RECT` для `shapes.gd` |
| `ext_post.py` | расширенные фоны на весь экран: центр вклеивается из оригинала, из комнаты вырезается слой прилавка |
| `pockets.py`, `fix_pockets.py` | убирают кремовый фон, застрявший между колёсами и в петельках игрушек |
| `loader_align.py`, `loader_apply.py` | выравнивают кадры загрузчика `web/loader.png` |
