# Silent Snow Night Gifts

Тихая ночная игра про упаковку новогодних подарков. Вы — частные индивидуальные предприниматели, рождественские эльфы. Ваша лавка появляется в самых неожиданных местах для тех, кому подарок нужен срочно, и работает только по ночам. Выручка идёт на развитие лавки.

**Играть в браузере:** https://iamgintonyc.github.io/silent-snow-night-gifts/

Это ранний играбельный прототип на Godot 4.7 (веб-версия, мышь или тач). Звук включается после первого клика.

## Как играть

1. Клиент заходит всегда с пустыми руками. Мы читаем его мысли (облачко с описанием получателя) и предлагаем подарок с полки «In stock». Угадали: клиент радуется и охотнее даёт чаевые. Не угадали: клиент сам выбирает нужный подарок.
2. На столе выберите способ упаковки (коробка или по форме), бумагу и направление (Horizontal или Vertical), потяните свободный конец из рулона (рулон остаётся виден на краю стола), отрежьте нужную длину ножницами, загните четыре края, заклейте скотчем где нужно и сами проведите ленту вокруг подарка.
3. Следите за сердечком терпения клиента вверху справа. Кривой подарок клиент может вернуть или не оплатить.
4. Расходы на материалы вычитаются из кассы, чаевые копятся в банке. После каждой ночи можно вложить выручку в развитие лавки.

Игра на английском, клиенты из разных стран: лавка путешествует по миру.

Всего 3 ночи (29, 30 и 31 декабря), 20 клиентов.

## Сборка и запуск

Нужен Godot 4.7.2 (и шаблоны веб-экспорта той же версии).

```bash
tools/build_web.sh        # экспорт в build/web
tools/serve.sh            # локальный сервер: http://localhost:8060
tools/deploy_pages.sh     # публикация build/web в ветку gh-pages
godot --headless --path . --script res://tools/smoke.gd   # автотест без окна
```

## Документы

- [TZ.md](TZ.md) — техническое задание, механика, экономика, лор.
- [ART_LIST.md](ART_LIST.md) — список объектов, для которых нужна качественная графика.

Графика и звук в прототипе почти целиком рисуются и синтезируются кодом. Исключение: у пяти клиентов (Mrs. Tanaka, Mateo, Ingrid, Mr. Okafor, Granny Zeynep) есть нарисованные кадры лица от тревоги до улыбки, `art/customers/` (ИИ-эскизы, подробности в ТЗ).
